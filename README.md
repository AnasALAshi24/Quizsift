# QuizSift

QuizSift is an AI-assisted assessment builder that turns educational PDFs or pasted text into editable glossaries and export-ready multiple-choice question papers.

## Project documentation

- [Complete product and technical overview](docs/final_project_overview.md)

## Core capabilities

- PDF and pasted-text input
- Ollama Cloud or local Ollama integration
- AI-assisted term and definition extraction
- Editable glossary review
- WH-style question generation with answer-leakage checks
- TF-IDF and cosine-similarity distractor selection
- Four ranked question-paper variants
- CSV, Word, and ZIP exports with answer keys

QuizSift is intended for educational content preparation. AI-generated material should be reviewed by a qualified instructor before use in formal assessment.
